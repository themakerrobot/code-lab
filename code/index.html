블록 · 파이썬 사용법
    
    
  

  

    
코딩하기

      
블록: 왼쪽 분류에서 블록을 끌어다 시작(깃발) 블록 아래에 붙여요.

      파이썬: 코드를 쓰거나 예제에서 골라요. 블록의 코드 탭에서 파이썬으로 옮길 수도 있어요.

    
실행 · 단축키

      

        
실행Ctrl + Enter

        
정지Esc — 무한 반복도 바로 멈춰요

        
바로 저장Ctrl + S (작업은 자동으로도 저장돼요)

      

    
결과 보기

      
결과: 글자와 그래프 · 그림: turtle (로봇이 걸어가며 그려요) · 코드: 블록이 바뀐 파이썬

      
turtle 에 키보드 · 마우스 · 타이머를 걸면, 코드가 끝나도 정지할 때까지 기다려요.

    
센서 · 내 AI · 목소리

      
웹캠 · 마이크로 손가락 수, 손 위치, 얼굴, 소리를 읽어요.

      내 AI: 가르치기에서 만든 AI 를 보관함에서 바로 골라 써요 (블록 '센서' 분류 · 파이썬 sensor.model()).

      AI 목소리로 말하기: 이 기기 안의 목소리로 읽어요.

      
영상 · 소리 · 글은 이 컴퓨터 밖으로 나가지 않아요.

    
저장 · 파일

      
보관함에 저장: 이름을 붙여 모아 두고, 상단바 보관함에서 다시 열어요.

      내보내기: 블록은 .json, 파이썬은 .py · 불러오기: .json · .py · .ailab.zip(내 AI)

      
한 번 열면 인터넷 없이도 열려요. 다른 컴퓨터로는 파일로 옮겨요.
